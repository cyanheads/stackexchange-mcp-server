# 0.1.10 — 2026-08-22

## Added

- **MCP protocol revision 2026-07-28** is available on every HTTP endpoint alongside the existing 2025 revisions.
- **Community health files** document contribution expectations, conduct, and private vulnerability reporting through `security@caseyjhand.com`.

## Changed

- **Tool inputs reject unknown keys by name**, and advertised output schemas include the structured error envelope so clients can validate success and failure results.
- **HTTP session mode** is explicitly `stateless` in `.env.example`, the container, and the README, so local and hosted runs resolve the same way.
- **Stack Exchange requests** use `fetchWithTimeout` with a 30-second deadline covering headers and response bodies; HTTP 400 envelopes still map to the existing `invalid_site` and `invalid_id_or_url` errors.
- **Runtime and project tooling** move to Bun 1.4.0 and TypeScript 7, typecheck tests as part of the main config, and omit unused optional peers from production containers.
- **Framework scripts, skills, and agent guidance** are synced to the current SDK v2 templates, including portable MCPB cleanup and stricter definition/package checks.
