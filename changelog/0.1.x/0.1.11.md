# 0.1.11 — 2026-09-09

## Fixed

- **`normalizeHtml` no longer clobbers escaped markup or drops tags.** Code spans are stashed before any tag pass runs and entities decode exactly once, at the end — fixing angle brackets vanishing from fenced/inline code and prose ([#13](https://github.com/cyanheads/stackexchange-mcp-server/issues/13)), chained entity passes fabricating markup from escaped text ([#22](https://github.com/cyanheads/stackexchange-mcp-server/issues/22)), and a link inside bold or italic losing its URL ([#23](https://github.com/cyanheads/stackexchange-mcp-server/issues/23)).
- **Tables, images, superscript/subscript, strikethrough, `<kbd>`, `<hr>`, and nested lists** are now rendered instead of collapsing into run-together text or being silently dropped ([#14](https://github.com/cyanheads/stackexchange-mcp-server/issues/14)).
- **Docker multi-arch builds** — the build stage now pins `--platform=$BUILDPLATFORM`, avoiding a QEMU allocator crash on the non-native leg of a `buildx` cross-build.

## Changed

- **Framework scripts, skills, and agent guidance** synced to the current SDK templates: release-PR-mode skills (`release-pr-review`), alias-aware `bun outdated` attribution in `devcheck`, and plugin-manifest version-parity checks in `lint:packaging`.
