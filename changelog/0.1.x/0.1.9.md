# 0.1.9 — 2026-07-16

## Fixed

- **`truncated` enrichment** — `search_questions`, `get_tag_faq`, and `get_thread` previously called `ctx.enrich.truncated()` unconditionally, flagging every response (including empty results) as capped. Each now gates on genuine capping: `search_questions`/`get_tag_faq` check the returned count against `pageSize` plus Stack Exchange's `has_more`; `get_thread` checks `answers.length < answerCount`. ([#7](https://github.com/cyanheads/stackexchange-mcp-server/issues/7))
- **`get_thread` accepted answer** — the accepted answer is now fetched explicitly and merged in when it ranks outside the top-`maxAnswers` by votes, so `acceptedAnswerId` is never reported with its body missing from `answers[]`. Adds optional `answerCount` (the question's total answer count) to the output schema and the `format()` header. ([#11](https://github.com/cyanheads/stackexchange-mcp-server/issues/11))
