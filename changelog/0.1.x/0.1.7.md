# 0.1.7 — 2026-07-16

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.10.9` → `^0.10.14`.
- **Supply-chain hardening** — `bunfig.toml` gains a 3-day `minimumReleaseAge` install gate (excluding `@cyanheads/mcp-ts-core`, adopted same-day) and the Socket `@socketsecurity/bun-security-scanner` install-time scanner (new `trustedDependencies` entry); `devcheck.config.json`'s framework-antipatterns ignore list and outdated allowlist (now includes `typescript`) updated to match.
- **`@biomejs/biome`** `^2.5.0` → `2.5.2` (pinned exact); **`@types/node`** `^26.0.0` → `26.1.1` (pinned exact); **`@socketsecurity/bun-security-scanner`** `^1.1.2` added; **`tsc-alias`** `^1.8.17` → `^1.9.0`.
- **Docker** — base image pinned to `oven/bun:1.3.14` (from floating `1.3` / `1.3-slim`); BuildKit cache mounts added to all three `bun install` layers; production install now runs with `--ignore-scripts`.
- **`package.json` `author`** normalized to `Casey Hand <casey@caseyjhand.com> (https://caseyjhand.com)`.
- New `.gitattributes` (LF normalization, binary asset handling, `linguist-generated` markers), `.github/FUNDING.yml`, and `.github/SECURITY.md`.

## Fixed

- **Non-BMP HTML entity decoding** — `decodeEntities()` swapped `String.fromCharCode` for a new `decodeCodePoint()` helper backed by `String.fromCodePoint`, so numeric character references above U+FFFF (emoji, rare CJK) decode correctly instead of truncating to a bogus BMP glyph. Out-of-range (>U+10FFFF) and surrogate code points map to the replacement character (`�`) instead of throwing. Reaches every caller of `decodeHtmlEntities`/`normalizeHtml` — titles, excerpts, site names, and author names/location. ([#8](https://github.com/cyanheads/stackexchange-mcp-server/issues/8))
- **Code-block language capture from SE markup** — the fenced-code regex in `html-normalizer.ts` now reads the `lang-`/`language-` token from the `<pre>` class (Stack Exchange's actual markup: `<pre class="lang-cpp prettyprint-override">`) instead of `<code>`. `get_thread` output now carries the correct fence language (` ```cpp `, ` ```java `) instead of always falling through to a bare fence. ([#9](https://github.com/cyanheads/stackexchange-mcp-server/issues/9))
- **Author display name and location decoding** — `getUser`'s `displayName`/`location` and `getThread`'s question/answer `authorName` now run through `decodeHtmlEntities`, so names like `Dane O'Connor` and `São Paulo` no longer leak raw entities (`O&#39;Connor`, `S&#227;o Paulo`). The same not-found guards in `getThread`/`getUser` also replace two `noNonNullAssertion` lint escapes with an early-return check on the destructured lookup. ([#12](https://github.com/cyanheads/stackexchange-mcp-server/issues/12))
