# 0.1.15 — 2026-09-19

## Changed

- **`@cyanheads/mcp-ts-core` 0.12.8 → 0.13.6** requires Bun ≥1.4 and moves synchronized guidance to `framework-skills/`.
- **Stack Exchange requests** use a shared queue and a 50-second total budget covering queue time, backoff, I/O, and retries.
- **HTTP defaults to stateless when `MCP_SESSION_MODE` is unset; an explicit stateful value still overrides it.**
- **Framework argument handling** accepts unambiguous case-style key aliases and validation-gated JSON-stringified arrays; unsupported keys still return argument errors with reason and recovery details.
- **Plugin manifests** expose the optional Stack Exchange API key as credential configuration, and the repository now carries its CodeQL analysis workflow.

## Fixed

- **Markdown table cells escape literal backslashes before pipes** so Stack Exchange table content remains intact ([#28](https://github.com/cyanheads/stackexchange-mcp-server/issues/28)).
