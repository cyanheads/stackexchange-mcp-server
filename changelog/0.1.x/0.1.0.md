# 0.1.0 — 2026-06-04

## Added

- `stackexchange_search_questions` — full-text search with tag, accepted-only, min-score, and sort filters
- `stackexchange_get_thread` — fetch complete Q&A thread (question + answers) as clean markdown; accepts question ID or URL; accepted answer first, then by score
- `stackexchange_get_tag_faq` — highest-voted answered questions for a tag via `/tags/{tag}/faq`
- `stackexchange_get_user` — user profile with reputation, badge counts, and top tags by answer score (2 parallel calls)
- `stackexchange_list_sites` — enumerate all ~190 SE network sites with optional name filter; returns `api_site_parameter` values for use in other tools
- HTML→markdown normalizer for SE post bodies (`<pre><code>`, `<p>`, `<strong>`, `<em>`, `<a>`, `<ul>/<ol>/<li>`, `<h1>`–`<h6>`, `<blockquote>`, inline `<code>`)
- Per-response `backoff` field honored; module-level backoff tracking prevents throttling
- `STACKEXCHANGE_API_KEY` optional env var lifts per-IP quota from ~300/day to ~10,000/day
- Attribution per CC BY-SA 4.0 included in thread output
