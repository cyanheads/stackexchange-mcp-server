# 0.1.4 — 2026-06-06

## Fixed

- **HTML entity decoding** — question titles and excerpts now have HTML entities decoded (e.g. `&#39;` → `'`, `&amp;` → `&`) in `searchQuestions`, `getThread`, and `getTagFaq`. ([#2](https://github.com/cyanheads/stackexchange-mcp-server/issues/2))
- **Out-of-range integer ID classification** — `get_thread` now throws `invalid_id_or_url` (not `invalid_site`) when the Stack Exchange API rejects the IDs field as a bad parameter. ([#3](https://github.com/cyanheads/stackexchange-mcp-server/issues/3))
- **`authorUserId` field** — `get_thread` now emits `authorUserId` on both the question and each answer, mapped from `owner.user_id`; `get_user` input description updated to reference the new field name. ([#4](https://github.com/cyanheads/stackexchange-mcp-server/issues/4))
- **Empty-result `notice` in `structuredContent`** — `search_questions`, `get_tag_faq`, and `list_sites` now declare `notice` in their enrichment schema so empty-result guidance appears in `structuredContent` for clients that consume it. ([#5](https://github.com/cyanheads/stackexchange-mcp-server/issues/5))
