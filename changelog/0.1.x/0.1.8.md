# 0.1.8 — 2026-07-16

## Fixed

- **`search_questions` `sort: "newest"`** — translates to Stack Exchange's `creation` sort internally; SE's `/search/advanced` only accepts `activity`, `creation`, `votes`, `relevance` and previously rejected `newest` with `bad_parameter`. The advertised `sort` enum is unchanged. ([#6](https://github.com/cyanheads/stackexchange-mcp-server/issues/6))
- **`search_questions` `minScore`** — now forces `sort=votes` (SE's only score-sorted mode) whenever set, taking precedence over the requested sort. Previously errored under the default `relevance` sort (`bad_parameter: min`) and silently filtered by date instead of score under `activity`. `minScore`'s `.describe()` now notes the override. ([#10](https://github.com/cyanheads/stackexchange-mcp-server/issues/10))
