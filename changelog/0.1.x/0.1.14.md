# 0.1.14 — 2026-09-09

## Fixed

- **`stackexchange_search_questions` excerpts no longer carry raw markdown.** `deriveExcerpt` drops blockquote markers and reference-definition lines, and flattens a `[text][label]` reference link to its text only when the body defines a matching label elsewhere — an unresolved bracket pair (array subscripts, driver error prefixes, adjacent tag mentions) is left untouched rather than deleted ([#26](https://github.com/cyanheads/stackexchange-mcp-server/issues/26)).
