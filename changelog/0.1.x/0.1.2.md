# 0.1.2 — 2026-06-05

## Added

- **`attribution` field** added to the `output` schema of `stackexchange_search_questions` and `stackexchange_get_tag_faq` — carries the CC BY-SA 4.0 license notice in the structured content channel. ([#1](https://github.com/cyanheads/stackexchange-mcp-server/issues/1))
- **CC BY-SA footer** appended by `format()` on both tools — `---\n*Stack Exchange Network — content licensed under CC BY-SA 4.0 (...)*` — mirroring the pattern already present in `stackexchange_get_thread`. ([#1](https://github.com/cyanheads/stackexchange-mcp-server/issues/1))
- **Tests** added for attribution in handler output and `format()` output on both tools; dedicated CC BY-SA footer test cases for each.
