# 0.1.5 — 2026-06-12

## Added

- **Truncation enrichment** — `search_questions`, `get_thread`, and `get_tag_faq` now emit `truncated`/`shown`/`cap` via `ctx.enrich.truncated()`, disclosing when results were capped at `pageSize`/`maxAnswers`.
- **`scripts/clean-mcpb.ts`** — post-pack bundle cleaner wired into `bundle`: runs `mcpb clean` then strips dependency-shipped agent-doc entries (`skills/`, `.claude/`, `.agents/`, `SKILL.md`) nested under `node_modules/` that root-anchored `.mcpbignore` patterns cannot reach.
- **Dockerfile `HEALTHCHECK`** — polls `/healthz` with `bun` (no curl/wget dependency); `APP_VERSION` build arg now stamps the `org.opencontainers.image.version` OCI label.
- **`techniques` skill** — catalog of response-shaping patterns, opening with the outline-on-overflow reference.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21` → `^0.10.6`.
- **`createApp()` identity** — sets `name` and `title` explicitly to `stackexchange-mcp-server` rather than relying on the scoped-package fallback.
- **`invalid_site` / `invalid_id_or_url` → `ValidationError`** — reclassified from `InvalidParams` across the service throw site and the `search_questions`, `get_thread`, `get_user`, and `get_tag_faq` error contracts.
- **`.mcpbignore`** — root-anchored every dev-directory pattern with a leading `/` so an unanchored `skills/` no longer also strips `node_modules/*/skills/`.
- **`STACKEXCHANGE_API_KEY` description** — trimmed the registration URL from the `server.json` env var descriptions.
- **Plugin manifests** — `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json` populated with description, author, homepage, and repository metadata.
- **Packaging linters** — `lint-packaging.ts` gains bundle-content and identity guards; `check-framework-antipatterns.ts` gains a `z.coerce.boolean()` env-flag rule and skips comment-line matches.
- **`@biomejs/biome`** `^2.4.16` → `^2.5.0`; **`@types/node`** `^25.9.2` → `^25.9.3`.
