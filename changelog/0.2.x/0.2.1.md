# 0.2.1 — 2026-11-21

## Added

- **Thread continuations** use `answersPage` and `commentsPage` with upstream next-page signals. Keep `maxAnswers` fixed between answer pages. Comment pages return up to 100 comments per API request ([#38](https://github.com/cyanheads/stackexchange-mcp-server/issues/38)).
- **Question closures** include the reason and date when available in search, FAQs, and threads. Threads also show original questions for duplicates ([#41](https://github.com/cyanheads/stackexchange-mcp-server/issues/41)).

## Changed

- **Site discovery** searches names, abbreviations, and audience descriptions, reports upstream site types, and includes meta sites when the filter contains the standalone word `meta` ([#42](https://github.com/cyanheads/stackexchange-mcp-server/issues/42)).
- **Bun** now requires version 1.4.4 or later.

## Fixed

- **Backoff** on a successful response holds the affected API method across sites and arguments. HTTP 429 and `throttle_violation` continue to hold all methods ([#35](https://github.com/cyanheads/stackexchange-mcp-server/issues/35)).
- **Thread links** accept short question and answer Share URLs and include a verified answer targeted by a long question URL when available ([#37](https://github.com/cyanheads/stackexchange-mcp-server/issues/37)).
- **User top tags** follow Stack Exchange's answer-score ranking ([#39](https://github.com/cyanheads/stackexchange-mcp-server/issues/39)).
- **Blank inputs** are normalized in search, FAQs, and user lookup. Search explains unfiltered browsing, blank sites resolve to Stack Overflow, and a blank FAQ tag returns `invalid_tag` ([#40](https://github.com/cyanheads/stackexchange-mcp-server/issues/40)).
- **Thread and user lookups** stop when the primary record is missing, and quota metadata reflects the last successful request.
